# Contributing

Thanks for helping! 
1. Open an issue first for anything bigger than a small fix.
2. Fork, create a branch, keep PRs focused.
3. Never commit `.env`, API credentials, or collected Product Hunt data.
4. Run `ruff check . && pytest -q` before opening a PR and describe how you tested.
5. Be kind — see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
